# Запись вебинара — настольное приложение

Версия 2.0 — отдельная программа с собственным окном вебинара. Chrome, расширения,
Node.js и Python на компьютере пользователя не нужны.

## Запуск готовой программы

Windows 10/11 x64: распакуйте **весь** архив `WebinarRecorder-2.0.0-win32-x64.zip`
и запустите `WebinarRecorder.exe`. Файлы рядом с EXE необходимы для работы;
не переносите EXE отдельно. Установка в систему не требуется.

1. Вставьте ссылку и нажмите «Открыть вебинар».
2. В открывшемся окне войдите на сайт и включите воспроизведение.
3. Выберите режим «Вебинар внутри программы». Если сайт открыл новое окно,
   обновите список источников и выберите окно с вебинаром.
4. Нажмите «Начать запись» и выберите файл.
5. Дождитесь статуса записи. Можно сворачивать оба окна и работать дальше.
6. Нажмите «Остановить и сохранить», дождитесь подтверждения.

Подробная инструкция: [USER_GUIDE.txt](USER_GUIDE.txt).

## Возможности

- Видео и звук конкретного встроенного окна вебинара, независимо от перекрытия
  другими окнами и сворачивания.
- Дополнительный режим захвата экрана или стороннего окна. Звук всей системы
  в этом режиме поддерживается в Windows.
- Пауза/продолжение, таймер, размер файла, выбор качества.
- Запись на диск частями с ограничением очереди в памяти.
- Незавершённая запись остаётся в `.partial`; после успешного завершения
  переименовывается в `.webm`. Готовый существующий файл заменяется только
  после успешного завершения новой записи.
- Значок в трее, запрос предотвращения автоматического сна, защита от случайного
  закрытия во время записи.
- Вход в вебинар сохраняется в отдельном профиле приложения.

## Ограничения

Запись свёрнутого **стороннего** окна зависит от того, продолжает ли оно рисовать
видео. Основной режим для фоновой записи — окно вебинара внутри программы.
Захват экрана записывает видимую картинку, включая перекрывающие окна.

Некоторые сайты блокируют вход во встроенном браузере; DRM-видео может быть
недоступно. Обход защиты не реализован. Совместимость с конкретной платформой
вебинара нужно проверить короткой пробной записью.

Компьютер должен оставаться включённым; при принудительном сне запись невозможна.
Формат WebM, до 1080p/30 кадров/с; MP4 и монтаж не реализованы. Длительность и
поиск по времени в незавершённых WebM могут определяться проигрывателем не сразу.
Ориентировочный размер — 1,2 или 2,3 ГБ/час в зависимости от качества и содержания.
Сборка не подписана сертификатом издателя.

Встроенный браузер отделён от системного профиля Chrome. Записи никуда не
отправляются. Сам сайт вебинара работает с сетью и сохраняет данные входа,
как в обычном браузере. Не публикуйте профиль и записи вместе с исходниками.

## Разработка

Node.js 22.12+:

```sh
npm ci
npm start
npm test
```

Интеграционная проверка требует ffmpeg/ffprobe и графический дисплей:

```sh
# Linux
xvfb-run -a npm run test:desktop
# Windows с установленным ffmpeg в PATH
npm run test:desktop
```

Тест открывает локальный движущийся вебинар со звуковым сигналом и захватывает
настоящий WebContents через Electron. Он скрывает нативные окна, проверяет изменение
видеокадров в записи, наличие звукового сигнала и паузу/продолжение. Модульные
тесты проверяют порядок и частичные операции записи, ошибку диска, защиту
незавершённого файла и удаление пустого файла.

## Сборка переносимой программы

Python 3.10+, без сторонних Python-библиотек:

```sh
python3 scripts/package.py --platform win32
python3 scripts/package.py --platform linux
```

Скрипт загружает закреплённую версию официального Electron, сверяет SHA256 с
файлом релиза и создаёт ZIP с программой. В сборку попадают только `desktop/`,
необходимые поля `package.json`, инструкция и Electron с его лицензиями.
Профили, записи, `.git`, тесты, `node_modules` и настройки окружения не включаются.
На Windows запускайте скрипт командой `python` вместо `python3`.

Для передачи через Telegram стандартным ботом большой ZIP можно разбить:

```sh
python3 scripts/split_delivery.py dist/WebinarRecorder-2.0.0-win32-x64.zip --out delivery
```

Получатель сохраняет все четыре части и `START-WINDOWS.cmd` в одну папку и
запускает CMD. Он объединяет части, проверяет SHA256, распаковывает ZIP средствами
PowerShell и запускает EXE. Административные права и загрузка из интернета не нужны.

GitHub Actions собирает Windows/Linux по ручному запуску или тегу `v*`;
ZIP доступен в артефактах запуска. Подписание и автоматическая публикация Release
не настроены. Реальный запуск Windows-сборки нужно проверять на Windows.

Техническая основа: [захват WebFrameMain через Electron](https://www.electronjs.org/docs/latest/api/session#sessetdisplaymediarequesthandlerhandler-opts),
[управление фоновой отрисовкой](https://www.electronjs.org/docs/latest/api/browser-window).
Пока встроенное окно скрыто, программа дополнительно запрашивает небольшой
снимок страницы через `capturePage`, поддерживая обновление кадров композитора.

Предыдущая версия расширения сохранена отдельно в `legacy-extension/`.
