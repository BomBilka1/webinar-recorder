# Запись вебинара

Расширение Chrome / Edge для компьютера. Записывает выбранную вкладку браузера
вместе с её звуком в локальный файл WebM. Можно переключать вкладки, работать в
других программах и сворачивать окно браузера. Интернет-сервис для хранения записей не нужен.

## Установка

1. Скачайте архив проекта и распакуйте в постоянную папку.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
5. Закрепите «Запись вебинара» в меню расширений браузера.

Нужен Chrome 116+ или совместимый Edge на Windows, macOS либо Linux.
На телефоне установка обычных расширений Chrome не поддерживается.

## Запись

1. Откройте вкладку вебинара и включите воспроизведение.
2. Нажмите значок расширения именно на этой вкладке.
3. Откроется отдельная вкладка управления. Выберите качество и нажмите
   «Выбрать файл и начать». Укажите новый файл `.webm`.
4. Дождитесь статуса записи. Можно свернуть браузер или работать в других окнах.
5. В конце вернитесь в управление и нажмите «Остановить и сохранить».
   Дождитесь сообщения о сохранении. Откройте видео, например, в VLC.

Записывается звук вкладки, а не микрофон и не звук остальных программ.
Звук вебинара при этом продолжает воспроизводиться через динамики/наушники.
Для записи другого вебинара снова нажмите значок на нужной вкладке.

## Ограничения

- Это запись **вкладки браузера**, а не произвольной программы на рабочем столе.
  Для Zoom/Teams используйте веб-версию; отдельные приложения не поддерживаются.
- Не закрывайте и не перезагружайте вкладку управления во время записи.
  Не закрывайте вкладку вебинара. При закрытии источника программа пытается
  завершить и сохранить доступную часть.
- Компьютер должен работать. Расширение запрашивает предотвращение автоматического
  сна, но не может записывать при выключении, принудительном сне или закрытом браузере.
- Захват вкладки работает в фоне, однако сайт может сам останавливать трансляцию,
  реагируя на потерю видимости. Защищённое видео может быть чёрным. Перед длинным
  вебинаром сделайте пробную минутную запись, свернув браузер, и проверьте звук и движение.
- Файл записывается последовательно на диск; всё видео не накапливается в памяти.
  Браузер обычно фиксирует файл только после корректного завершения. При аварии
  браузера/компьютера незавершённая запись может потеряться.
- Обычное качество — ориентировочно 1,2 ГБ/час, высокое — 2,3 ГБ/час.
  Реальный размер зависит от содержания. Убедитесь, что на диске достаточно места.
- Видео до 1920×1080, до 30 кадров/с; фактическое разрешение зависит от вкладки.
  Пауза, MP4, монтаж и одновременная запись нескольких вебинаров не предусмотрены.
- Записывайте материалы, для которых у вас есть разрешение.

## Приватность и разрешения

Записи остаются на вашем компьютере. В расширении нет аналитики, загрузки на сервер,
сторонних библиотек и доступа ко всем сайтам.

- `activeTab` — доступ к вкладке после нажатия значка.
- `tabCapture` — видео и звук выбранной вкладки.
- `power` — запрос предотвращения автоматического сна на время записи.

Реализация следует [официальному примеру Chrome записи в отдельной вкладке](https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture#record-audio-and-video-in-a-new-tab).

## Проверка разработчиком

Без установки зависимостей, Node.js 18+:

```sh
node --test tests/core.test.mjs
node --check background.js
node --input-type=module --check < recorder.js
```

Автотесты проверяют последовательность записи на диск, обработку ошибки диска и
таймер. Реальный вебинар, звук и сворачивание проверяются вручную в браузере:
запись 60 секунд движущегося видео со звуком, 30 секунд со свёрнутым окном,
остановка, просмотр файла. Дополнительно проверьте отмену выбора файла,
закрытие вкладки источника и повторную запись.

Дополнительный тест в настоящем Chromium с синтетическими видео/аудиодорожками
и записью в файловую систему браузера:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium --no-shell
node tests/browser-smoke.cjs
```

В этом тесте выбор вкладки и файла подменяется; он проверяет MediaRecorder,
сохранение WebM и состояние интерфейса, но не системное сворачивание окна и
не разрешение на захват реального сайта.
